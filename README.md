# Primitive DB

Primitive DB — простая консольная база данных на Python.

## Описание

Проект реализуется в рамках учебного задания.
База данных позволяет создавать и удалять таблицы,
добавлять, просматривать, изменять и удалять записи.

## Технологии

- Python 3.12
- uv
- JSON
- PrettyTable
- Ruff

## Установка

uv sync

## Запуск

uv run project
